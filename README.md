# 秘书终结者

会议室自动抢订工具的发布页。这里只放发布文件，不放源码。

## 下载

在右侧 [Releases](https://github.com/TianLin0509/mishu-terminator/releases/latest) 里下载 `MishuTerminator-<版本>.exe`，放进一个固定的文件夹后双击运行（可改名为 `秘书终结者.exe`）。
第一次运行时，Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」。

## 更新

程序左下角「软件更新」会提示新版本，点开即可更新，平时只下载几十 KB 的程序代码。
每个版本的 `latest.json` 都带发布者的签名，程序只安装签名正确的更新。

## 注意

程序文件夹里的 `browser_profile` 保存着你的登录状态，不要把它或整个程序文件夹发给别人；要分享，请用程序里的「设置 → 生成分享包」。
